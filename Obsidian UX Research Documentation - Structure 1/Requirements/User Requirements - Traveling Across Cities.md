# Derived User Requirements

1. With the system, the user must be able to recognise timely updates on delays, platform changes, and connection times (information) to plan their journey effectively (condition).
2. With the system, the user must be able to recognize multilingual and icon-based instructions (information) at train stations to navigate the facility (condition).
3. With the system, the user must be able to use functional elevators and escalators (resource) to ensure seamless navigation across the station (condition).
4. With the system, the user must be able to recognize risky connections and select suggested alternatives (information) when necessary for uninterrupted travel (condition).
