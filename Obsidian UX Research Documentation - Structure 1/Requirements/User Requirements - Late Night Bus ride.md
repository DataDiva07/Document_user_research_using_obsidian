
# Derived User Requirements

1. With the system, the user must be able to recognise multilingual, simplified timetables with clear weekday/weekend differentiation (information) when planning their journey (condition).
2. With the system, the user must be able to recognise clear guidelines on ticket validity for night buses (information) both on the timetable and onboard (condition).
3. With the system, the user must be able to view visible and illuminated route maps inside the bus (resource) when traveling at night (condition).
4. With the system, the user must be able to use mobile apps with real-time bus tracking and stop notifications (resource) when traveling to ensure confidence (condition).**
