# Derived User Requirements

1. With the system, the user must be able to recognise multilingual user interface options (information) when attempting to purchase a ticket (condition).
2. With the system, the user must be able to view discounts available, such as student discounts or regional offers (information), under a user-friendly display (condition).
3. With the system, the user must be able to select discounts available, such as student discounts or regional offers (information), under a user-friendly display (condition).
4. With the system, the user must be able to review the destination and time (information) before completing a ticket purchase (condition).
5. With the system, the user must be able to select either English or German as the interface language (resource) to improve usability for non-German speakers (condition).
6. With the system, the user must be able to select a payment method, such as credit card, cash, or mobile payment (resource), to ensure payment flexibility (condition).
7. With the system, the user must be able to access user-friendly navigation apps (e.g., DB Navigator) with visual and audio support (information) to aid in navigation (condition).
8. With the system, the user must be able to recognise and follow visual and icon-based instructions (information) at ticket counters and kiosks for improved clarity (condition).
